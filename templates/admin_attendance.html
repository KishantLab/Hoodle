⚙️ Configure QR Rotation Interval

The dynamic QR code displayed on the classroom projector screen rotates cryptographically based on this interval. Any photos, WhatsApp screenshots, or shared links expire automatically once the timer expires. You may set any duration 20 seconds or higher.

seconds
Minimum requirement: 20 seconds. Recommended: 20s (standard classroom), 30s–45s (large auditoriums).

🛡️ How Anti-Proxy QR Rotation Works

1. Cryptographic HMAC Token: The server computes an 8-character rotating token based on SHA256(SecretKey + CourseID + SessionType + TimeBlock). Each token is tied strictly to its specific time window.
2. Photo & Proxy Rejection: If a student takes a picture of the screen and sends it on WhatsApp or Telegram to an absent friend, the token expires after the configured interval (e.g. 20s or 30s) and cannot be scanned from outside the hall.
3. Smooth Transition Grace Period: To prevent students who clicked "Scan" right as the code rotated from being rejected, the backend validates against the current block and the immediately preceding block.
4. Real-Time Projector Sync: Active projector screens automatically pick up the new expiration interval without needing any teacher browser refresh.
