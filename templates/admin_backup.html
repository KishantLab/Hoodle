💻 Terminal Bare-Metal Restoration Guide

If the server hard drive is replaced or re-formatted, install the fresh codebase and run the restoration script directly via SSH to pull everything back from GPU2: 

# 1. SSH into the production server
ssh kishan@10.10.14.104

# 2. Enter application directory
cd /data/admin/ACCLLMS

# 3. Pull latest backup from GPU2 and restore database & files
bash scripts/hoodle_restore.sh --from-gpu2

# 4. Confirm system status
sudo systemctl status accl-lms.service
