What does "{{ backup_config.retention_days }}-Day Retention" mean?
Every night at 02:00 AM, Hoodle LMS creates a complete hot snapshot archive (database, files, lockers, submissions). {{ backup_config.retention_days }}-Day Retention means the system keeps daily snapshots for the past {{ backup_config.retention_days }} days (providing you with {{ backup_config.retention_days }} individual rollback points in history). Any backup older than {{ backup_config.retention_days }} days is automatically deleted (pruned) locally and on the remote machine so your storage disks never run out of space.

💻 Terminal Bare-Metal Disaster Recovery Guide

If the server hard drive is replaced or re-formatted, install the fresh codebase and run the restoration script directly to restore everything from your remote backup server: 

# 1. SSH into the production server
ssh kishan@10.10.14.104

# 2. Enter application directory
cd /data/admin/ACCLLMS

# 3. Pull latest backup from remote backup server and restore database & files
bash scripts/hoodle_restore.sh --from-remote

# 4. Confirm system status
sudo systemctl status accl-lms.service
