💡 Got Error 534 (WebLoginRequired) during SMTP Verification?
Google requires device authorization for accounts sending mail via SMTP from server or campus IP addresses. Follow these quick steps to resolve it:
  1. Turn ON 2-Step Verification: Go to Google Account → Security and ensure 2-Step Verification is active.
  2. Generate an App Password: Visit myaccount.google.com/apppasswords, create a 16-letter App Password named "Hoodle LMS", and enter it in the form below.
  3. Authorize Server IP via DisplayUnlockCaptcha: If Google still blocks connection with Error 534, open accounts.google.com/DisplayUnlockCaptcha while logged into this Google account in your browser, click "Continue", and re-run the verification test within 10 minutes.
